An MCP server for the group's application platform

Naval Group, March to August 2026, final-year project

Naval Group relies on a shared application platform that many applications are built on. I designed and built, on my own, an MCP server that joins the platform's core features, so that an AI can make calls to the different applications built on it.

It exposes 11 tools and will be added to the platform during the next migrations, making it available to all of those applications.

A timeline of Warhammer's Old World

Personal project, since October 2026

I never found a clear timeline of the Warhammer Fantasy and The Old World setting online. Dates are scattered across dozens of books and wikis, and they don't always agree.

So I made one, from the Old Ones to the Storm of Chaos, filterable by faction and region. Each event cites its sources and flags where they disagree. The timeline itself is in French. See the timeline
